## On the bench

**Annot**<br>
Feedback on live prototypes, without the screenshot ping-pong. Hover over any section of a page, click, write the note. Each note keeps a cropped screenshot of the exact spot and goes straight to Asana, or out as a PDF report. I built it for my own team, so everyone can review a prototype I share, designer or not.<br>
`Chrome extension` · `v0.1.0`

**Looka**<br>
I use several AI coding tools a day and had no idea what any of it cost. Looka reads the session logs Claude Code and Codex CLI already leave on your machine and shows tokens, model time, and what the same work would cost at API rates. It updates live.<br>
`Desktop app` · `Node`
