I've designed software for about 15 years. Tax filing, compliance tools, learning platforms, page builders for Joomla and WordPress. For most of that time my work stopped at the handoff: I sent a Figma file, someone else built it, and I found out later what got lost on the way.

## On the bench

**BMQ**<br>
Feedback on live prototypes, without the screenshot ping-pong. Hover over any section of a page, click, write the note. Each note keeps a cropped screenshot of the exact spot and goes straight to Asana, or out as a PDF report. I built it for my own team, so everyone can review a prototype I share, designer or not.<br>
`Chrome extension` · `v0.1.0`

**Looka**<br>
I use several AI coding tools a day and had no idea what any of it cost. Looka reads the session logs Claude Code and Codex CLI already leave on your machine and shows tokens, model time, and what the same work would cost at API rates. It updates live.<br>
`Desktop app` · `Node`

**bricks.md**<br>
A UI kit for SaaS apps that you don't copy from a website. Install it once, then ask Claude Code, Codex or Cursor for a brick by name (`btn-2`, `chart-4`, `cmdk`) and it gets fetched and fitted to your project. 118 bricks across 7 groups, from app shells to AI chat.<br>
`Paid` · `HTML + Tailwind v4`
